# Tasmay Infotech storefront preview

A responsive, browser-ready storefront concept for Tasmay Infotech.

## Open it

Open `index.html` in a modern browser. An internet connection loads the optional Google Fonts; the page layout and product illustrations are built into the included files.

## Included in this preview

- Responsive desktop and mobile layouts
- Product categories, search, sorting, and product detail views
- Add to bag, remove, quantity controls, and a cart saved in this browser
- Checkout form preview and order summary
- Animated CSS 3D product scenes, pointer response, and reduced-motion support
- Tasmay logo, address, phone, email, PAN, and GSTIN in the footer

## Important before launch

Products, specifications, and prices are illustrative sample content. The checkout is a local preview only: it does not send or retain customer details, create an order, or collect payment. Before accepting live orders, connect a secure backend for product/inventory, accounts, orders, shipping, taxes, and customer data, then configure a payment provider account and server-side payment verification. Do not put secret payment keys in browser code.

The design takes cues from Apple's spacious product storytelling and category-led store browsing, while using original Tasmay colors, logo, product illustrations, and copy.
